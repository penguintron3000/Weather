An Android weather app for tracking cities and getting personalized, weather-aware guidance.

## Features

- Secure account registration and login with user-specific saved cities
- Add, view, and remove cities from a personal weather dashboard
- Current temperature, conditions, humidity, and wind details from OpenWeatherMap
- Google Maps city views with coordinates and location markers
- Gemini-powered weather insights with timely suggested questions and tailored answers
- AI-generated city imagery that reflects the current weather and time of day
- Personalized app themes generated from a user’s description
